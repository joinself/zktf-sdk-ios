# zktf-sdk-ios

This repository contains the [Swift Package Manager](https://www.swift.org/documentation/package-manager/) (SPM) distribution of the ZKTF SDK for iOS.

For source code, documentation, and issues, please refer to the main repository: [joinself/zktf-sdk-ios-src](https://github.com/joinself/zktf-sdk-ios-src).

## Installation

Add this package to your project using Swift Package Manager:

```swift
dependencies: [
    .package(url: "https://github.com/joinself/zktf-sdk-ios.git", from: "0.1.0")
]
```
